# Coffee Sales Analysis

Which drinks bring in the most revenue at our coffee shop?

## Setup

conda:
```
conda env create -f environment.yml
conda activate coffee_sales
```

venv:
```
python -m venv .venv
source .venv/bin/activate      # Windows: .\.venv\Scripts\activate
pip install -r requirements.txt
```

## How to Run

* `python main.py` cleans the raw data and saves a chart to `outputs/`
